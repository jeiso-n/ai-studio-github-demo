# AI Studio GitHub Demo

This is a small demo project created in Google AI Studio to learn how an AI Studio app connects to GitHub.

## What we are doing

1. Build a simple React app in Google AI Studio.
2. Sign in to GitHub from the AI Studio GitHub settings.
3. Create a public GitHub repository for the app.
4. Sync the app files from AI Studio to GitHub.
5. Keep the project in GitHub so changes can be tracked and shared.

## Demo app

The app displays a heading and a button. Clicking the button changes the heading, demonstrating a basic working React interface.

## Tools

- Google AI Studio
- React
- GitHub

This repository is a learning demonstration of the connection and sync workflow between Google AI Studio and GitHub.
